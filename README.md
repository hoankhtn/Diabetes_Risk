# Diabetes_Risk
- LLM_USAGE.md: Những hoạt động dùng AI
- __init__.py: File này để nhận diện src đang ở đâu và chạy
- utils.py: Các hàm tiện ích, kiểm tra số dòng (Row count check)
- preprocessing.py: Làm sạch dữ liệu số, chuỗi, ngoại lai, missing data
- features.py: Gộp bảng (D1), xử lý thời gian (D2), tạo biến mới (D3)
- stats_and_ml.py: Kiểm định/Bootstrap (D5), Robustness (D6) & ML Pipeline
- visualization.py: Các hàm vẽ biểu đồ chuẩn hóa (đủ title, axes, unit, legend)
